# Roadmap

Windows first; Mac after Windows qualification; Android and iOS development after the macOS app is completed and validated. Preserve the fast spreadsheet/Gantt workflow and protect original project data.

The owner authorizes a complete visual redesign, with `.mpp` compatibility and broad practical feature coverage as priorities. The former requirement to imitate the Office/Project shell is superseded. See [design direction and acceptance criteria](DESIGN-DIRECTION.md).

1. Complete recovery/performance qualification and current Windows native stress gate.
2. Finish graphical ChatGPT setup and reviewed Gantt/timeline image attachments.
3. Typed custom fields/statuses, saved views, richer Board/Calendar editing.
4. Scheduling explanations, broader qualified constraints/actuals, Gantt gestures and scenario comparison.
5. Timephased capacity, work/cost tracking and qualified leveling.
6. Dashboards, risks/issues/decisions and templates.
7. Portfolios and cross-project dependencies.
8. Local rules, typed AI/MCP proposals and optional project MCP host.
9. Conflict-aware personal file sync.
10. Hardened Windows release and broader MPP operation/field compatibility matrix.
11. Actual Mac M1 validation and platform packaging.
12. After macOS completion, define the shared mobile architecture and phone/tablet feature matrix; develop and qualify Android and iOS apps. See [mobile plan](MOBILE-PLAN.md).

Full Microsoft Project parity is not established. Android and iOS are confirmed future targets gated on macOS completion; their framework, detailed feature scope and release dates remain to be decided. Hosted collaboration and public forms remain separate scope decisions. No delivery dates are promised by this backlog.

## Delivery cadence

Package a release after each two completed user-facing features, with per-version release.md and validation evidence. Versions 0.3.0 and 0.3.1 deliver the first four features; see [release history](../releases/release.md). The next priority is the [UI-first release sequence](UI-RELEASE-PLAN.md): responsive workspace, density/focus mode, confident editing and a grouped inspector together in 0.3.2 (merging the previously planned 0.3.3). Gantt and timelines remain the focus. Typed statuses and editable Board/Calendar follow their model prerequisites, with compatibility checks throughout. This is an ordered backlog, not an assertion that the roadmap is complete.
