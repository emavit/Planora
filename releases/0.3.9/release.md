# Planora 0.3.9 — Familiar columns, clearer controls

Windows preview · 19 October 2026 · Previous release: 0.3.8

## Changes from 0.3.8

- Microsoft Project Entry preset: Indicators, Task Mode, Task Name, Duration, Start, Finish, Predecessors and Resource Names. Open Choose columns, select the preset, then Apply columns. Cancel preserves your current configuration.
- Colored vector command icons: teal for planning, purple for resources, amber for milestones/notes, red for PDF/destructive actions and blue for general tools. Light and dark palettes are separate; labels remain available and primary buttons retain their contrasting icon foreground.
- Rounded context menus and dropdown rows, consistent typography and theme-aware hover/selection colors.

## Run

Keep the complete release folder together and launch Planora.exe. No .NET installation is needed for this Windows package. Existing .mpp and .planora identities and saved settings remain unchanged.

## Validation and limitations

The package includes icon, workspace, timeline, Resource Sheet, template, scheduling, recovery and close/save checks plus native Windows stress evidence. The public MPP corpus still has 10 known failures out of 88 stages; full Microsoft Project compatibility is not claimed. No macOS qualification or GitHub publication is implied by this local Windows release.
