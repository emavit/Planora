# Planora 0.3.10 — One-click timelines

Windows preview · 19 October 2026 · Previous local release: 0.3.9

## Changes from 0.3.9

Click **Hide timelines** above the Gantt or task table to reclaim chart space. The same button becomes **Show timelines**. The setting is remembered; timeline lanes, tasks, formatting and dates remain intact. This focused release was requested immediately rather than waiting for a second feature.

## Included from recent local releases

Modern Planora branding, Apple/Office-style ribbon, colored command icons, rounded Gantt bars, coordinated dropdowns, Microsoft Project Entry column preset, editable inspector, saved views, template library and Resource Sheet refresh improvements.

## Run on Windows

Extract the complete Planora-0.3.10-win-x64.zip, then run Planora.exe inside the extracted folder. Keep the files together. The package includes its .NET runtime.

## Qualification

Windows preview, not a final cross-platform release. The public MPP corpus retains 10 known failures out of 88 stages (78 passing). Full Microsoft Project compatibility is not claimed. macOS testing and subsequent Android/iOS work remain pending. Validation logs and file hashes are included. Only public and synthetic examples are included.
