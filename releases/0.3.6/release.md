# Planora 0.3.6 — planning ribbon

Previous version: 0.3.5.

## Two improvements

1. Ribbon commands are arranged in softly bordered groups with headings above the controls, quieter selected tabs and consistent spacing. Previous/next arrows expose overflow commands on smaller windows and disable at their limits. Hide controls collapses the command area; selecting a tab reopens it with the correct label. The All ribbon tabs menu remains available.
2. A new default Planning tab gathers working controls for task/milestone creation, columns, Gantt zoom/fit/date limits, Today, selected-task navigation, timeline creation/task selection/date limits, automatic scheduling, links, calculation, colors and PDF export. Existing detailed tabs and menu commands remain available.

## How to use

If your workspace is compact, click Show ribbon. Open Planning for daily chart work. Gantt dates and Timeline dates control their separate axes. New timeline creates a lane and shows the timeline; Add selected tasks adds the current task selection. Use the side arrows when groups extend past the window width. Hide ribbon or F11 restores more planning space.

## Validation and limits

Workspace validation now includes default Planning selection, working Gantt zoom, timeline creation and selected-task inclusion, collapse/reopen labels, original tab access and absence of project edits from view-only commands. Exact packaged checks and native stress results are appended below.

This is a Windows preview. The public MPP gate retains 10 known failures. Chart drag previews, expanded spreadsheet selection, full template gallery and local project hub remain future work; this release does not deliver the gallery previously proposed under version 0.3.6. macOS remains unqualified. Existing Resource Sheet and inspector fixes are retained.
