# Planora 0.3.8 — Modern identity, familiar planning

Windows preview · 19 October 2026 · Previous release: 0.3.7

## Changes from 0.3.7

- New indigo/aqua schedule-bar logo, consistent app-header/window/Windows icons, refined wordmark and brand guidelines. The name remains Planora.
- Apple-inspired surfaces combined with Office-style ribbon captions below commands, group separators and a clearer selected tab. Tighter spacing and quiet overflow arrows keep the schedule central.
- Rounded, slightly taller Gantt bars with progress fills clipped to the bar silhouette. Existing custom colors, date endpoints, dependency routes and baseline positions are preserved.
- Softer neutral table headers. Task table, Gantt, multiple timelines and optional inspector keep their existing arrangement.

## Use

Extract or copy the whole release folder, then run Planora.exe. Do not copy the executable alone. Show ribbon exposes the Planning commands; Gantt Chart Format retains chart controls. Existing .planora files, settings and recovery paths retain their identities.

## Validation and limitations

Package checks cover core planning, automatic scheduling, durable history, recovery, close/save flow, workspace editing, timelines, Resource Sheet edits and planning library. Native Windows stress uses generated data only. See bundled validation results for exact outcomes.

The public MPP corpus still has 10 known failures (78 passing stages of 88). This release does not fix calendar-reference, baseline writer or producer-XML differences and does not claim full Microsoft Project compatibility. macOS and mobile remain unqualified. No live paid AI calls or private project examples are used.
